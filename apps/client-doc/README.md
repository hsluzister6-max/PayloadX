# PayloadX Client Document

Standalone React app with the client facing product overview for PayloadX.

## Run

```bash
cd apps/client-doc
npm install
npm run dev
```

Opens at [http://localhost:3005](http://localhost:3005).

## Build

```bash
npm run build
npm run preview
```

## Contents

1. Summary
2. What is PayloadX
3. How it works (day to day + deploy modes)
4. Technologies (desktop, Rust, backend, MCP)
5. System flows (request, env, sync, MCP)
6. Workflows explained with run charts
7. Features at a glance
8. Platforms and delivery
9. Getting started

Flowcharts are rendered in the app with simple step diagrams (no Mermaid dependency).
